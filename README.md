# English Sentence Trainer

A mobile-friendly English sentence practice site with 83 reviewed IELTS translation prompts.

## Use

Open the GitHub Pages site and choose **开始练习**. In the trainer, tap the English sentence to hear it; long-press a word to see its Chinese meaning. Question progress and drafts are saved in the current browser on the current device.

## Publishing

This repository contains the ready-to-publish static site. GitHub Pages publishes the repository root from the `main` branch. To update the site, replace the site files in the root with a fresh build from the trainer project and push the changes.

Dictionary data attribution and license are in `output/dictionary/ATTRIBUTION.md` and `output/dictionary/LICENSE.txt`.
